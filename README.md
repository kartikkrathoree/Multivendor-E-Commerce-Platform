# 🛒 Multivendor E-Commerce Platform

A Spring Boot REST API project for a Multivendor E-Commerce Platform built using Java, Spring Boot, Hibernate, MySQL, Lombok, Maven, and Swagger UI.

## 🚀 Technologies Used

- Java 17
- Spring Boot
- Spring Data JPA (Hibernate)
- MySQL
- Lombok
- Maven
- Swagger UI

## ✨ Features

- User Management CRUD
- Product Management CRUD
- Category Management CRUD
- Cart Management
- Customer Profile Management
- Order Management
- Order Item Management
- MySQL Database Integration
- REST APIs
- Swagger UI for API Testing

## 📂 Project Structure

- Entity
- Repository
- Service
- Controller
- DTO
- Exception

## 🗄 Database

Database: MySQL

Tables:
- Users
- Product
- Category
- Cart
- Customer_Profile
- Orders
- Order_Item

## ▶️ Run the Project

1. Clone the repository
2. Configure MySQL in application.properties
3. Run the Spring Boot application
4. Open Swagger:

http://localhost:8080/swagger-ui/index.html
